🏥 요양원 이용 가이드
① 로그인
• 아이디: 요양원명 (예: 서부시립)
• 비밀번호: 관리자가 발급한 비밀번호 입력
• 로그인 후 본인 요양원 의뢰 내용만 조회 가능 (타 요양원 열람 불가)
② 새 의뢰 작성
• 상단 탭 ✏️ 새 의뢰 작성 클릭
• *필수항목: 환자명, 생년월일, 층/호실, 방문요청일, 현재증상
• 신환(신규 환자): 주민번호 전체, 주소, 보호자 연락처 반드시 입력
• 진단명 복수 선택 가능 / 기타 선택 시 특이사항란에 상세 기재
• 의뢰내용 복수 선택 가능
• 처방전·소견서 첨부 가능 (JPG·PNG·PDF, 파일당 5MB 이내)
• 💾 의뢰 저장 버튼으로 최종 제출
③ 의뢰 목록 조회 및 검색
• 상단 탭 📋 의뢰 목록에서 본인 요양원 의뢰 전체 확인
• 환자명·층/호실로 검색 가능
• 📅 기간 필터: 날짜 직접 입력 또는 빠른 버튼 (오늘·이번주·이번달·지난달) 클릭
• 상태 필터: 신규 / 처리완료 구분 조회
• 카드 하단 신규 → 접수 대기 / 처리완료 → 검사결과 확인 가능
④ 검사결과 확인 및 처리완료
• 의뢰 카드 클릭 → 상세 화면 이동
• 🔬 검사결과 이미지 섹션에서 관리자가 업로드한 결과 이미지 확인
• 이미지 클릭 시 전체화면 확대 (← → 키로 넘기기 가능)
• 검사결과 이미지가 업로드된 후 ✅ 처리완료 확인 버튼 활성화
• ⚠️ 결과 이미지가 없으면 처리완료 버튼이 비활성화됩니다
⑤ 엑셀 출력
• 의뢰 목록 화면 우측 상단 📊 엑셀 출력 버튼 클릭
• 현재 적용된 기간·상태 필터 조건 그대로 출력됨
• 파일명: 가정간호의뢰_서부시립_기간_날짜.xlsx
👑 관리자 전용 기능 가이드
① 전체 관리 탭
• 모든 요양원의 의뢰를 한 화면에서 조회·관리
• 요양원별 의뢰 수·대기 건수 통계 카드 자동 집계
• 요양원·상태·기간 복합 필터링 가능
• 각 의뢰 수정·삭제 가능
• 📊 엑셀 출력: 필터 조건 그대로 전체 의뢰 엑셀 다운로드
② 검사결과 이미지 업로드
• 의뢰 상세 화면 → 🔬 검사결과 이미지 섹션
• 업로드 영역 클릭 또는 드래그 앤 드롭
• 지원 형식: JPG·PNG·GIF·PDF / 파일당 최대 3MB / 최대 10장
• 업로드 완료 시 요양원 화면에 즉시 반영
• 이미지 위 마우스 호버 → 🗑 버튼으로 개별 삭제 가능
• 이미지 업로드 후 ✅ 처리완료 버튼으로 완료 처리
③ 요양원 계정 관리
• 🏢 요양원 관리 탭에서 계정 생성·수정·삭제
• 새 요양원 추가: ➕ 카드 클릭 → 요양원명·아이디·비밀번호 입력
• 계정 수정: 각 카드의 ✏️ 수정 버튼 → 아이디·비밀번호 변경 가능
• 계정 삭제: 🗑 삭제 버튼 (해당 요양원의 의뢰 데이터는 유지됨)
• 계정 변경 시 로그인 화면 안내문 즉시 업데이트
④ 이메일 알림 설정 (EmailJS 상세 설정 방법)
요양원이 새 의뢰를 저장하면 지정된 이메일로 자동 알림이 발송됩니다.
📌 STEP 1 — Email Service 연결 (Gmail / 네이버 등)
1. dashboard.emailjs.com 로그인
2. 왼쪽 메뉴 Email Services 클릭
3. Add New Service 버튼 클릭
4. 사용할 이메일 서비스 선택 (예: Gmail)
5. Connect Account 버튼 클릭 → 구글 계정으로 로그인 허용
6. Service ID 확인 (예: service_xxxxxxx) → 복사해 두기
7. Save 버튼 클릭
📌 STEP 2 — Email Template 생성 (메일 양식 만들기)
1. 왼쪽 메뉴 Email Templates 클릭
2. Create New Template 버튼 클릭
3. 아래 내용을 각 필드에 입력:
Subject (제목):
[가정간호 신규의뢰] {{facility}} - {{patient}} 님

Content (본문):
요양원: {{facility}}
환자명: {{patient}}
층/호실: {{room}}
방문요청일: {{visitDate}}
진단명: {{diagnoses}}
현재증상: {{symptoms}}
의뢰내용: {{referrals}}
특이사항: {{special}}
보호자연락처: {{guardian}}
작성일시: {{createdAt}}
메모: {{memo}}

To Email (수신자):
{{to_email}}
4. Save 클릭 → Template ID 확인 (예: template_xxxxxxx) → 복사해 두기
📌 STEP 3 — Public Key 확인
1. 왼쪽 메뉴 Account 클릭
2. General 탭 → Public Key 항목 확인
3. 키 값 복사 (예: user_xxxxxxxxxxx)
📌 STEP 4 — 이 프로그램에 입력 후 저장
1. 상단 탭 ⚙️ 이메일 설정 클릭
2. 아래 4가지 입력:
  • Public Key: STEP 3에서 복사한 값
  • Service ID: STEP 1에서 복사한 값
  • Template ID: STEP 2에서 복사한 값
  • 수신 이메일: 알림 받을 이메일 주소
3. 💾 설정 저장 버튼 클릭
4. 📤 테스트 메일 버튼으로 정상 수신 확인
⚠️ 주의사항: EmailJS 무료 플랜은 월 200건까지 발송 가능합니다. 초과 시 다음 달 1일에 자동 초기화됩니다. Gmail 사용 시 구글 계정의 "보안 수준이 낮은 앱 허용" 또는 앱 비밀번호 설정이 필요할 수 있습니다.
☁️ 데이터 저장 안내 (Firebase 클라우드)
• 모든 데이터는 Firebase 클라우드 서버에 실시간 저장됩니다
• 여러 PC에서 동시에 사용해도 데이터가 자동으로 공유·동기화됩니다
• 요양원이 의뢰를 저장하면 관리자 화면에 즉시 반영됩니다
• 인터넷이 끊겨도 재연결 시 자동으로 동기화됩니다
• 중요한 데이터는 주기적으로 📊 엑셀 출력하여 백업하세요
