🏥 요양원 이용 가이드

• 아이디: 요양원명 (예: 서부시립)
• 비밀번호: 관리자가 발급한 비밀번호 입력
• 로그인 후 본인 요양원 의뢰 내용만 조회 가능 (타 요양원 열람 불가)
② 새 의뢰 작성
• 상단 탭 ✏️ 새 의뢰 작성 클릭
• *필수항목: 환자명, 생년월일, 층/호실, 방문요청일, 현재증상
• 신환(신규 환자): 주민번호 전체, 주소, 보호자 연락처 반드시 입력
• 진단명 복수 선택 가능 / 기타 선택 시 특이사항란에 상세 기재
• 의뢰내용 복수 선택 가능
• 처방전·소견서 첨부 가능 — 사진(JPG·PNG)은 자동 압축되어 용량 걱정 없이 첨부 가능, PDF는 600KB 이하만 첨부 가능 (PDF가 크면 사진으로 촬영해서 첨부 권장)
• 💾 의뢰 저장 버튼으로 최종 제출
③ 의뢰 목록 조회 및 검색
• 상단 탭 📋 의뢰 목록에서 본인 요양원 의뢰 전체 확인
• 환자명·층/호실로 검색 가능
• 📅 기간 필터: 날짜 직접 입력 또는 빠른 버튼 (오늘·이번주·이번달·지난달) 클릭
• 상태 필터: 신규 / 처리완료 구분 조회

• 의뢰 카드 클릭 → 상세 화면 이동

• 이미지 클릭 시 전체화면 확대 (← → 키로 넘기기 가능)
• 검사결과 이미지가 업로드된 후 ✅ 처리완료 확인 버튼 활성화
• ⚠️ 결과 이미지가 없으면 처리완료 버튼이 비활성화됩니다

🧾 환자별 (영수증)
• 환자를 선택하면 영수증 형식으로 출력됩니다
• 상단에 총 본인부담금이 큰 글씨로 표시되고, 아래에 방문일자별 처치·처방 내역과 금액이 나열됩니다

🏥 요양원별 (전체)
• 우리 요양원 전체 환자를 가나다순으로 정리하여 환자별 소계 + 전체 합계를 한눈에 확인

기간 선택: 일별(오늘)/주별/월별/전체 버튼 또는 날짜 직접 선택 (방문요청일 기준)
출력: 🖨 인쇄/PDF 저장 버튼으로 영수증을 인쇄하거나 PDF로 저장, 📊 엑셀 출력으로 동일 내용을 엑셀 파일로 다운로드
※ 본 요양원에 등록된 환자 데이터만 조회됩니다 (타 요양원 정보는 표시되지 않음)
⑦ 📢 공지사항
• 관리자가 등록한 공지를 상단 탭 📢 공지사항에서 확인
• 읽지 않은 공지가 있으면 탭 옆에 빨간 숫자로 표시
• 로그인 시 새 공지가 있으면 자동 팝업으로 안내 (필요 시 "오늘 하루 다시 보지 않기" 체크)
• 제목 클릭 시 내용 펼침/접기, 첨부된 이미지·파일 확인 가능
• ⭐ 표시는 중요 공지, 🎯 표시는 우리 요양원 전용 공지
⑧ 🚫 가정간호 중단 안내
• 본인부담금이 한 달 동안 한 건도 수납완료되지 않은 환자는 다음 달 1일부터 가정간호 중단 처리됩니다.
• 중단된 환자는 의뢰지 작성이 불가합니다 (저장 시 안내 메시지 표시).
• 로그인 시 중단 환자 목록이 팝업으로 자동 안내되며, 의뢰 목록 화면 상단에도 빨간 안내 배너로 항상 표시됩니다.
• 본인부담금이 수납완료 처리되면 자동으로 해제되어 의뢰지 작성이 다시 가능해집니다. 별도 요청 없이 자동 처리됩니다.
• 자동 모드는 2026년 06월 수납 현황부터 적용됩니다. 수동 예약은 2025년 01월부터 소급 적용이 가능합니다.

① 전체 관리 탭
• 모든 요양원의 의뢰를 한 화면에서 조회·관리
• 요양원별 의뢰 수·대기 건수 통계 카드 자동 집계
• 요양원·상태·기간 복합 필터링 가능
• 각 의뢰 수정·삭제 가능
• 📊 엑셀 출력: 필터 조건 그대로 전체 의뢰 엑셀 다운로드
② 검사결과 이미지 업로드
• 의뢰 상세 화면 → 🔬 검사결과 이미지 섹션
• 업로드 영역 클릭 또는 드래그 앤 드롭
• 지원 형식: JPG·PNG·GIF·PDF / 파일당 최대 3MB / 최대 10장
• 업로드 완료 시 요양원 화면에 즉시 반영
• 이미지 위 마우스 호버 → 🗑 버튼으로 개별 삭제 가능
• 이미지 업로드 후 ✅ 처리완료 버튼으로 완료 처리
③ 💰 본인부담금 입력 및 처리완료
• 의뢰 상세 화면에서 검사결과 업로드 후, 가정간호 본인부담금 입력란에 금액 입력
• 금액 입력 후 ✅ 처리완료 버튼 클릭 → 상태 변경 + 본인부담금 동시 저장
• 금액을 입력하지 않으면 0원으로 처리됩니다
• 처리완료 후에도 의뢰 상세에서 ✏️ 금액 수정 가능
④ 💰 본인부담금 — 전체 요양원 조회
상단 탭 💰 본인부담금에서 관리자는 요양원을 선택하여 조회할 수 있습니다.

• 🧾 환자별: 요양원 선택 → 환자 선택 → 영수증 형식 출력
• 🏥 요양원별: 특정 요양원 선택 시 해당 요양원 환자를 가나다순으로 정리
• 요양원 선택을 "전체"로 두고 🏥 요양원별 선택 시 → 모든 요양원을 요양원별 → 환자별(가나다순)로 그룹화하여 한 번에 출력 (전체 합계 포함)
• 🖨 인쇄/PDF 또는 📊 엑셀로 출력 가능 (기간: 일/주/월/전체, 방문요청일 기준)
⑤ 요양원 계정 관리
• 🏢 요양원 관리 탭에서 계정 생성·수정·삭제
• 새 요양원 추가: ➕ 카드 클릭 → 요양원명·아이디·비밀번호 입력
• 계정 수정: 각 카드의 ✏️ 수정 버튼 → 아이디·비밀번호 변경 가능
• 계정 삭제: 🗑 삭제 버튼 (해당 요양원의 의뢰 데이터는 유지됨)
• 계정 변경 시 로그인 화면 안내문 즉시 업데이트
⑥ 이메일 알림 설정 (EmailJS 상세 설정 방법)
요양원이 새 의뢰를 저장하면 지정된 이메일로 자동 알림이 발송됩니다.
📌 STEP 1 — Email Service 연결 (Gmail / 네이버 등)
1. dashboard.emailjs.com 로그인
2. 왼쪽 메뉴 Email Services 클릭
3. Add New Service 버튼 클릭
4. 사용할 이메일 서비스 선택 (예: Gmail)
5. Connect Account 버튼 클릭 → 구글 계정으로 로그인 허용
6. Service ID 확인 (예: service_xxxxxxx) → 복사해 두기
7. Save 버튼 클릭
📌 STEP 2 — Email Template 생성 (메일 양식 만들기)
1. 왼쪽 메뉴 Email Templates 클릭
2. Create New Template 버튼 클릭
